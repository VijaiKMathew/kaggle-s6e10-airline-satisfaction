Design Pattern: Residual Boosting with Margin Injection
The AdditiveGLM computes global linear margins using high-signal nested target encodings solved via the exact newton-cholesky algorithm. The ResidualGBDT then takes these linear margins as an init_score offset. This restricts the tree booster to learning exclusively non-linear residual interactions, preventing tree depth explosion and memorization of sparse fraud anomalies.

Leakage Containment Rule
Global operations (such as computing target encodings, global mean imputation, value counts, or standard scaling across all 699,960 rows prior to splitting) cause fatal out-of-fold information leakage. In this architecture, all transformer states are computed strictly on train_fold and projected onto val_fold.

Why Rank Normalization Dominates Probability Averaging
Under ROC AUC, the metric depends exclusively on the pairwise ordering of pairs $(y_i = 1, y_j = 0)$. Arithmetic averaging $\frac{1}{M}\sum p_m$ is corrupted if one model outputs uncalibrated extreme probabilities (e.g., $0.9999$). Rank averaging guarantees that every model has an identical uniform marginal distribution $U(0, 1)$, preventing calibration distortion from destroying ensembling gains.

from scipy.stats import rankdata

def post_process_preds(oof_preds, test_preds):
    norm_oof = rankdata(oof_preds) / len(oof_preds)
    norm_test = rankdata(test_preds) / len(test_preds)
    return norm_oof, norm_test
Experiment Slot C: Leaderboard Shakeup Safeguard Analysis

The public leaderboard tests only ~30% of the test set (~90,000 rows). The remaining ~70% (~210,000 rows) comprises the private leaderboard. To survive public-to-private shakeup:

  • Never select a submission based purely on a lucky public leaderboard spike ($\le +0.0002$) if CV drops.
  • Always pair one high-performing blend with a conservative, regularized 5-fold baseline.
  • Enforce rank-averaging to protect against distribution shift in unlabelled test probabilities.
